⚙️ 데이터 관리

단어와 문장을 JSON 파일로 내보내거나, 편집한 파일을 가져와서 콘텐츠를 추가할 수 있어요.

📥 내보내기 (다운로드)

현재 데이터를 JSON 파일로 저장합니다. 메모장이나 편집기로 열어서 수정할 수 있어요.

📤 가져오기 (업로드)

편집한 JSON 파일을 불러옵니다. 기존 데이터에 추가됩니다 (같은 ID는 덮어쓰기).

📋 JSON 파일 형식 안내

단어 파일 구조:

{"vocab": {
  "카테고리명": [
    {"en":"apple", "ko":"사과", "ex":"I eat an apple."},
    {"en":"book", "ko":"책", "ex":"I read a book."}
  ]
}}

문장 파일 구조:

{"topics": [
  {"id":"mytopic", "level":"basic",
   "emoji":"🎵", "title":"음악",
   "subtitle":"I like music",
   "items":[
    {"en":"I like music.",
     "ko":"나는 음악을 좋아해.",
     "choices":["나는 음악을 좋아해.",
       "음악이 싫어.","노래를 불러.",
       "악기를 쳐."]}
  ]}
]}

level 값: basic, elementary, intermediate (초등) / opic-il, opic-im1, opic-im2 (OPIc)

🗑️ 사용자 데이터 초기화

업로드한 추가 데이터만 삭제합니다. 기본 내장 데이터는 유지됩니다.
